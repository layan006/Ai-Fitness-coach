# AI Fitness Coach

An AI-powered fitness coaching application designed to provide users with personalized workout guidance through an interactive AI fitness coach.

## Overview

This project explores how AI can be integrated into a fitness application to create a more personalized and interactive coaching experience.

Users can interact with the AI fitness coach to receive fitness guidance, ask questions, and get personalized recommendations.

## Features

- AI-powered fitness coaching
- Interactive chat interface
- Personalized fitness guidance
- Workout-related recommendations
- User-friendly interface
- Backend server for handling AI requests
- API integration
- Persistent project structure for future feature development

## Technologies

- JavaScript
- HTML
- CSS
- Node.js
- OpenAI API
- npm
